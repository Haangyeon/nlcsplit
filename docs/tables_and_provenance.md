## 2. Method

1. **核与约定**：`w0=√(C|∇ρ|⁴/ρ⁴+4πρ/3)`，`κ=b(3π/2)(ρ/9π)^{1/6}`，
   `Φ=−3/(2gg'(g+g'))`，`g=w0(r_i)R²+κ(r_i)`（**同中心配对**）。
   交叉配对 `g=w0(r_j)R²+κ(r_i)` 偏高 +0.13(水)/+0.42(Ar)/+0.91(苯) kcal/mol，
   是错的 [nlcsplit/step_e_kernel.py；随包的 `nlcsplit/tests/test_kernel.py::test_fast_matches_naive_bit_for_bit`
   把"同中心快路径 = 朴素双重循环"钉在 rel 1e-13 上]
   （**2026-10-04 更正**：这里原来写的是"IDE 的 S3 合成箱独立复现：same-centre 与 PySCF 内核差
   −2.8e−19 Ha"。那个绝对差是另一台会话里现算的，stdout 从没入库（本仓只留下了一句转述），
   所以它现在**不可核**——按本文件自己的规矩撤回，改引随包测试的判据。丢掉的信息是"绝对差小到
   1e-19 Ha 量级"这一条，它并不支撑上面那个结论，故不补跑）
2. **半份/整份约定**：`pair_energy(A,B)` 给半份，`inter[(A,B)]=2·blk`，
   故 `E_nl=Σintra+Σinter` 可加性严格成立（实测残差 **0.00e+00 至 6.94e−18 Ha**）
   [evidence/recompute/20260929T010500Z_step1_geomfix.out；CentOS step_c.out]
3. **恒等式（方法论要点）**：`E_NLC = 双重和 + β∫ρ`，而 β 为常数、∫ρ ≡ 电子数，
   所以 **β∫ρ 在任何 superposition 差中精确抵消**（实测 ΔE_loc = +3.736e−05 kcal/mol，
   level 1）⇒ 只对双重和做片间分解是严格的，不是近似
   [step_f_dispersion.py 输出；step_c 独立复现同一结论]
   ⚠ 但**别把这条推广到"片段绝对量"**：单片段的局域项 `E_loc,A = β·N_A`
   就是一句 Becke 布居，`β = 0.004847 Ha = 3.0415 kcal/mol/电子`，
   所以 **span_scheme(E_loc,A) ≡ β · span_scheme(N_A)**——恒等式而非估算。
   水二聚体 level 3 实测四方案 ΔN_A = 9.865e−2 e ⇒ **0.3000 kcal/mol**，
   比配对项的方案跨度（八体系 0.003–0.248 kcal/mol）大一个量级。
   读法：这是**一切用 Becke 布居的分解法共有的**性质，不是本方法的贡献或优势；
   报片段绝对能时必须连同此条一起报。[scratch/probe_iB.py；PROGRESS 08:40 条]
   口径疑虑另需说清两点。**其一**（软/硬局域项之差）：软归属与 owner 硬归属对局域项确实只差在浮点级——水二聚体、6-31g\*、ωB97X-V、**level 3**（ne=20）实测四方案里软硬布居最大差：**构造几何 = 8.686e−07 个电子（×β = 2.642e−06 kcal/mol）**、**官方 S22 几何 = 1.527e−06 个电子（×β = 4.644e−06 kcal/mol）**（`evidence/population/20260930T201142Z_stepk_soft-vs-hard-constructed.out`、`evidence/population/20260930T200927Z_stepk_soft-vs-hard-official.out`）。旧稿只写"≤8.7e−7（β·Δ ≤ 2.6e−6）"——那是构造几何那一档，官方几何到 1.5e−6；两者都远小于上面的方案间跨度 β·ΔN_A ≈ 0.30–0.33 kcal/mol，所以 `fragment_decomposition(soft=)` 里"Becke 因子乘了两次"在数值上无关紧要，不必当成竞争口径。**其二**（`base_w` 的错法）：`base_w` 配一次因子是**错的**口径，但机制**不是**
   "子网格重叠区重复计数"——拼接点表里没有重复坐标（`partition_factors` 返回的点表与 `atom_partition` 相同），
   真正是每个原子的径向网格都铺到整个分子、每个子网格把同一空间函数各积了一遍；而且倍率**不是常数**：
   水二聚体（构造几何 `geomlib.h2o_dimer()`）真实密度 ρ 上 `Σ base_w·ρ` 在 level 0/1/2/3 = **100.19 / 690.26 / 279.08 / 94.75**（ne=20，
   隐含倍率 5.0 / 34.5 / 14.0 / 4.7，非单调、也不收敛到 natm=6）。钉住它的是 `nlcsplit/tests/test_partition_factors.py`
   两条：`test_soft_attribution_owner_masked_matches_analytic_gaussian`（光滑高斯锚，按 owner 掩膜复现 ∫h=π^{3/2}）
   与 `test_base_w_on_real_density_is_not_a_measure_at_all`（真实密度 ρ，证明倍率根本不是常数）。
4. **归属方案**：Becke / Becke 半径修正 / Becke–Treutler / Stratmann + 最近原子硬分区，
   全部走 PySCF `gen_grid.get_partition` + `radi.BRAGG_RADII`。
5. **远区裁剪**：`rho_floor` 默认 1e−12。水二聚体（构造几何、6-31g\*、becke，`step_d_floor.py`）扫 floor 1e−8…1e−16 五档：验收区间 floor=1e−10…1e−14 三档片间项跨度 **level 1 = 2.1e−11、level 2 = 4.2e−11 Ha**（日志同行给的 kcal/mol 读数是 0.000000，括号里那个才是 Ha）；含 1e−8、1e−16 端点的全五档跨度按 `P_frz` 最大单点偏移 ~1e−8 kcal/mol、四舍五入到 0.000000——floor 在哪档都可当实现细节。代价是丢弃 10.7%（lvl1,1e−16）–22.6%（lvl2,1e−8）的网格点（其上电子数 ≤2.3e−6）[step_d_floor.py]
