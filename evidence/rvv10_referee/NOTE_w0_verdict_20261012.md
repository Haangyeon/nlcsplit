# W0 判定台账 · "PySCF 把 rVV10 做成 VV10"这条疑点**证伪**（2026-10-12）

> 原件：`20261012T043309Z_w0_pyscf_side.out`、`orca_run/{control,test}__*.out`(+各自 `.out.rc`)、
> `20261012T045423Z_w0_forced_params.out`。全部 `.rc`=0，12 个 ORCA 跑 `runs_failed=0`。

## 一、原疑点

`pyscf/dft/xcfun.py` L314-L316 把 `B97M_V` / `WB97M_V` / `WB97X_V` 三行给**同一组 (6.0, 0.01)**
（那是 VV10 的参数），而同表 L320 给 `SCAN_RVV10` 的是 (15.7, 0.0093)。
加上核形是写死的 VV10 有理阻尼 ⇒ 猜想"PySCF 用 VV10 实现 rVV10 泛函"。

## 二、三臂实测（同几何 GMTKN55 官方 S22、同基组 6-31G\*、同 `grids.level=1`）

ΔE_NLC（超位置差，kcal/mol；β·∫ρ 在差里精确抵消）：

| 体系 | PySCF `wb97mv`(as is, 6.0/0.01) | PySCF 强制 rVV10 (14.05/0.0359) | ORCA `WB97M-V` | ORCA `WB97X-V`（控制档） |
|---|---|---|---|---|
| (H2O)2 | −0.5969 | **−0.1027** | **−0.5965** | −0.5931 |
| (CH4)2 | −0.5195 | **−0.1019** | **−0.5188** | −0.5160 |

- 控制档残差 0.0004（(H2O)2）与已入库先例（`evidence/orca_widen/`：ORCA −0.5931 / PySCF −0.5935）**逐位对上**
  ⇒ 这条对照通路的门通过，才有资格用测试档说话。
- 测试档残差 0.0004 / 0.0007 ⇒ 与控制档同量级。
- 强制 rVV10 那一臂使 ΔE_NLC 动 **0.4942 / 0.4177 kcal/mol**，即 (b,C) 在这个精度上**完全可分辨**（残差的 ~700 倍）。

⇒ 判读落 **R1**：两程序对 ωB97M-V 用的是同一组 (6.0, 0.01)，而且这个差别**不是**测量噪声掩盖出来的
（因为强制换参数会动半 kcal）。

## 三、为什么这组参数是对的（权威出处，非我方口径）

ωB97M-V 的原始标题就把非局域项写作 **VV10**："ωB97M-V: A combinatorially optimized, range-separated
hybrid, meta-GGA density functional **with VV10 nonlocal correlation**"。
而 rVV10 的评估文献（Mardirossian, Pestana, Head-Gordon 2017 JCTC）明确写：
"a value of **b = 6** (fortuitously the same as that in B97M-V) is suitable for B97M-rV"。
⇒ `"-V"` 结尾的这一族用 VV10/(6.0,0.01) 是**发表时的设定**，不是实现的错。
我原先把 rVV10 的通用参数 (14.05, 0.0359) 记成了 ωB97M-V 的参数 —— 那是 `"-rV"` 一族的写法。

## 四、仍未判的一件事（别把它当已解决）

`SCAN_RVV10` / `SCANL_RVV10` 拿到的是 rVV10 的**参数**，但走的仍是写死的 VV10 **阻尼形式**。
这一条**没能**在本轮判：本机 ORCA 6.0.1 不认 `SCAN-RVV10`（实测 INPUT ERROR），
`strings` 里也没有任何 RVV10 功能名 ⇒ **ORCA 给不出 rVV10 形式的裁判**，libxc 只导出参数表
（`xc_nlc_coef` 一路在本轮全返回 −1，见 `20261012T042506Z_libxc_nlc_table.out`，记"未取得"）。
要在这一列上下任何结论，必须自己按原始定义实现 rVV10 的阻尼形式，并找到独立裁判；
拿不到裁判就只能写成"未验"，不许写成"实现缺陷"。

## 五、对本论文的正面影响（这条要留着）

参数量级差 0.42–0.49 kcal/mol，**是整个归属歧义带 0.0034–0.2468 的 8–11 倍**。
⇒ 正文应当主动用它给自己设上限：归属歧义是真实的、可逐格量化的，但**比 (b,C) 的选取差异小一个量级**；
这也解释了为什么我们固定 (b,C)、只换归属方案。审稿人若拿"参数才是大头"来压，这一节就是预备答复。
