## 一、错了什么

包外家族外测量脚本 `evidence/common_grid/hirshfeld_crossfamily.py` 原第 87 行：

```
rel = X0 - mol.atom_coord(a, unit="Angstrom")        # 错：两个单位相减
```

`X0` 来自 `partition.scf_grid` → `mf.grids.coords`，**PySCF 网格坐标恒为 Bohr**；
`Mole.atom_coord(atm_id, unit="Angstrom")` 返回 Å。于是每个自由原子被放在
"离原点只差一个 Bohr/Å 换算因子"的错位置上，**离坐标原点越远的原子挪得越多**。

2026-10-12 作者拍板"两侧同修"，现已改为与网格同为 Bohr（取默认单位）：

| 侧 | 文件 | 改动 |
|---|---|---|
| 包外测量脚本 | `evidence/common_grid/hirshfeld_crossfamily.py` | `atom_coord(a)`（去 `unit` 实参） |
| 包内归属实现 | `nlcsplit/partition.py` `hirshfeld_factors` | 同步去 `unit` 实参，函数头写明为何不再与归档逐位相符 |

## 六、由此作废/改写的说法（逐条点名）

1. **作废**："跨构造带顶 0.3898"、"带顶由苯-水的 Hirshfeld 撑起 +0.1430"、"甲烷那格比值 12.17"
   —— 三者都是单位错位的产物。10-10 那次已经撤回过一句"八格全落在已发表归属带内"，
   这次是第二次撤回，**同一列数字连续两次出问题，说明它本来就不该进任何结论**。

3. **结论形状改写（这是正面收获）**：归属歧义**不是选冷门分区方案造成的**——
   换到 Voronoi / Hirshfeld 既不消除它、也基本不放大它（四格绝对增量 ≤0.028 kcal/mol），
   它就长在标准工具链内部（Becke 家族那两个开关）。这比"跨构造带更宽"更难被反驳。
4. 比值列仍只作参考（分母家族内跨度自身跨 65 倍），**报绝对增量**是本表唯一诚实的口径。
