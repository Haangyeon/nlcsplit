## 2. 分子是什么、分母是什么

生成脚本 `nlcsplit/step_h_s22.py`，字段定义在同文件 `:109-111`：

```python
dxc  = (d["e_xc"]  - m["e_xc"])  * KCAL      # :109
dnlc = (d["e_nlc"] - m["e_nlc"]) * KCAL      # :110
dtot = (d["e_tot"] - m["e_tot"]) * KCAL      # :111
```

`d` = 复合物，`m` = Σ 单体@复合物几何（`:103-107`，单体在**各自自己的**SCF 里算，不是冻结密度）。`KCAL = 627.509474`（`nlcsplit/step_f_dispersion.py:24`）⇒ **单位 kcal/mol**。

**分母 `dxc` 是"全量 ΔE_xc"，且它把 VV10 项包含在内。** 三点互证：
1. `e_xc = float(vhf.exc)`（`step_f_dispersion.py:63-64`），而 `:68` 写的是 `e_semi = e_xc - e_nlc_libxc`——即"从 ΔE_xc 里**减掉** NLC 才得到半局域+精确交换那一份"。同文件 docstring `:41-45` 讲得很直白：`E_xc(其余) := vhf.exc − E_NLC`。
2. `:71` 的闭合断言 `e_tot == e_nuc + e1 + ecoul + e_xc`（实测残差 ≤1.8e-11 kcal/mol）⇒ `e_xc` 必须吃掉所有 XC 类项，VV10 也不例外。
3. 数值复核：日志里 `ΔE_xc其余 = +0.2850`、`ΔE_NLC = −0.5167`，和 = `−0.2317` ≡ 印出来的 `ΔE_xc −0.232`。**加性闭合成立 ⇒ 分子 ⊂ 分母。**
   稿件自己也是这么写的：`paper/main.md:142-143` `ΔE_xc = ΔE_xc^rest + ΔE_NLC`；表头 `paper/main.md:388` 写 `dE_xc (total)`。

**分子 `dnlc` 不是"片段分解后的 E_NL(A,B)"，而是 VV10 项的超位置全差**，按 `step_h_s22.py:10` 自己的定义：
`ΔE_NLC 其中非局域项那一份（= 片间成对项 + 片内项的跨单体差，β∫ρ 精确抵消）`。
纯"片间成对项"是**另一个字段** `pint.becke`（P_frz，`:62` `res["inter"][(0,1)] * KCAL`），甲烷 = −0.474，两者差 8%（比值 0.92 就是这个）。
⇒ 若汇报把 223% 说成"片段分解给出的 E_NL(A,B) 占比"，那是**换了分子**：用 P_frz 作分子，甲烷是 **204.3%**，水 16.2%，全表范围变成 16–204%。

**口径四要素（缺一不可，汇报里一个都没写）**：
ωB97X-V / 6-31G\* / 网格 level **1** / **cpcorr=false（未做 BSSE 校正）**，单位 kcal/mol，几何为 GMTKN55 官方 S22 `struc.xyz`（`nlcsplit/geomlib.py:147-156`：甲烷=S22_08，水=S22_02；8 行 = 7 个 S22 成员 + 苯二聚体第二构型，见 `PROGRESS-nlcsplit.md:2490`）。

**含不含 BSSE？分母不含，而且不含是"没办法"而不是"选择更好"。** 全仓库存不到 CP 之后的 ΔE_xc：`counterpoise()`（`step_h_s22.py:69-96`）对 ghost 单体只取 `mf.e_tot`（`:95`），从不调 `terms()`，所以 ghost 的 `e_xc` 从未被记录；`step_h_l2cp.json` 只有 `dcp`（相互作用能）。
⇒ 唯一能给的 CP 版对照是**换分母为 ΔE_int(CP)**：甲烷 `0.517/0.466 = 110.9%`，水 `0.593/6.129 = 9.7%`（`evidence/l2cp/...:16`、`:6`）。
**注意方向：BSSE 修不修，甲烷这个数只会更大（77.9% → 110.9%），不会变小。** 所以未校正是**保守**写法，审稿人拿这个咬你咬不住——但汇报里"不含 BSSE"必须说出来，否则读者会以为分母是收敛到化学精度的结合能。

## 3. 分子分母同号吗？>100% 是怎么来的？有没有取绝对值

### 3.1 同号：**同号**。分子 `−0.517`、分母 `−0.232`，都是负的 ⇒ 比值天然为正 `+2.228`。
**没有用绝对值掩盖符号**，也没有"符号相反取 abs"。稿件印的是带符号相除（`nlcsplit/step_f_dispersion.py:134,149` 的 `dnlc/dxc*100` 就是原值）。
独立印证：`evidence/claims_audit/E_c1_live_recompute.out` 把"带符号"与"绝对值"两种算法都打了出来，甲烷两者同为 223.0% ⇒ 取 abs 不改变任何事，符号没有被藏起来。

### 3.2 >100% 的机制：分母是**近零抵消的差**，不是"分母小"这么轻描淡写
`ΔE_xc^rest = ΔE_xc − ΔE_NLC = +0.285`（`MAIN-skeleton.md:182` 明列该列；`paper/main.md` 的 Fig.1 caption 也给了 `+0.285 against a VV10 term of -0.517 kcal/mol`；全精度 `+0.2849516`）。
甲烷这一行：|ΔE_xc|/|ΔE_NLC| = **0.4484**（3 位小数为 44.9%）——两个绝对值 0.3–0.5 kcal/mol 量级、符号相反的项相减，剩下 0.232。
所以 223% 字面意思是"**VV10 吸引项比整个 XC 净变化还大一倍多，因为 XC 其余部分是排斥的**"，
而不是"VV10 贡献了 223% 的相互作用"（那是 77.9%，见 §4）。
全表只有甲烷这一行 `rest > 0`、只有这一行 `ratio > 100%`（重算输出：`rows with ratio > 100%: ['甲烷二聚体']`）。

### 3.3 最关键的一条：**本仓库自己的代码禁止对这一行报百分比**

`nlcsplit/step_f_dispersion.py:128-134`：
```python

    # "非局域占 ΔE_xc 510%" 这种数毫无信息量，必须改报绝对项。
    if dxc == 0 or abs(dnlc / dxc) > 2.0:
        print(f"    ⚠ 分母抵消：|ΔE_NLC|/|ΔE_xc|={abs(dnlc/dxc):.1f} ⇒ 不报占比，"
              f"只报两个绝对项（吸引与排斥分开看）")
```
同一判据在汇总处也有一遍：`:149` `flag = "⚠ 分母抵消" if dxc == 0 or abs(dnlc / dxc) > 2.0 else ...`。
甲烷 `|dnlc/dxc| = 2.228 > 2.0` ⇒ **闸门触发**（其余 7 行 0.16–0.97，全部不触发）。

而 `MAIN-skeleton.md:185-187` 正是拿这条判据来解释 >100% 的：
`⇒ 甲烷二聚体"其余 XC"是 **+0.285 排斥**（占比 >100% 就是这个意思，所以正文用绝对项并列，不用百分比排序——见 step_f 的分母抵消警告）。`

⇒ **骨架稿的处置意见是"不用百分比排序"，但 `paper/main.md` 的 Table 1 末列和摘要/§4/§6 三处（`:58/:544/:668`）全都用了百分比，并且 223% 还是宣传上的最高点。**
这是稿件与自己实现的直接冲突，比"数字对不对"严重：它意味着作者已经知道这个占比在这一行不携带信息，仍然把它放进 headline。
（`step_h_s22.py` 自己没实现这条判据——它只印绝对量，从不印百分比；223% 纯粹是人/下游 markdown 现场相除的产物，所以没有任何自动护栏会拦它。）

## 4. "根本不是小修正"这个解读，靠不靠得住

**这个比值本身撑不起它**，因为"占 ΔE_xc 多少"回答的是**"VV10 是不是 XC 里一个固定分数/能不能被叫作色散"**（稿件原意，`paper/main.md:544-549`、`:668-670`），
而"小修正"是**量级判断**，分母该换成体系的总结合能。两件事的分母不同。

### 4.1 朴素量（kJ/mol 绝对值）——**不支持**这个说法，至少不支持得这么响

| 体系 | ΔE_NLC (kcal/mol) | ΔE_NLC (kJ/mol) | kT@298 K = 2.479 kJ/mol |
|---|---|---|---|
| 水二聚体 | −0.5935 | **−2.48** | 1.00 kT |
| 甲烷二聚体 | −0.517 | **−2.16** | 0.87 kT |

2.2 kJ/mol 与 2.5 kJ/mol——甲烷那一行**绝对值还是全表偏小的**。单看 kJ/mol，"根本不是小修正"这话说不出口，
审稿人一句"0.5 kcal/mol，你的方案不确定度都有 0.004–0.247 kcal/mol（`paper/main.md:546`）"就能顶回来。

### 4.2 换成正确分母（总相互作用能）——**支持，而且更强**

| 体系 | ΔE_NLC/ΔE_int（超位置，level 1） | ΔE_NLC/ΔE_int(CP)（level 2，`evidence/l2cp`） |
|---|---|---|
| 水二聚体 | **7.6%**（−0.593/−7.816） | **9.7%**（−0.593/−6.129） |
| 甲烷二聚体 | **77.9%**（−0.517/−0.664；全精度 77.80%） | **110.9%**（−0.517/−0.466） |
| 氨二聚体 | 13.1% | 18.4% |
| 苯···甲烷 | 78.7% | 116.9% |

⇒ **甲烷那一行真正有力的事实不是"223% of ΔE_xc"，而是"VV10 单项（−0.52 kcal/mol）比整个算出来的结合能（−0.66 未校正 / −0.47 CP 校正）还大"**。
这个说法不需要近零分母、不受 step_f 那条判据约束、单位干净、可直接引 `evidence/l2cp/...:16`。**建议汇报改用它。**

### 4.3 "弱束缚小体系里"这个限定语有两个硬伤

1. **16% 那一端自己就是反例。** 水二聚体是这套里最典型的"弱束缚小体系"（6 原子，氢键），
   而它恰恰是全表 VV10 占比最低的一行：16% of ΔE_xc、7.6% of ΔE_int。把它和 223% 并列写进
   "所以它根本不是小修正"，等于用一件支持反例的事去支撑一个结论。
   **只有 223% 那一端（即甲烷一个体系、一个几何）在支撑这个说法。**
2. **"小体系"盖不住这张表。** ≤10 原子的只有 3/8 行（水 6、氨 8、甲烷 10）；
   其余 5 行是 15、16、17、24、24 原子。`16%~223%` 这个区间是**跨 6–24 原子**取到的极值，
   不是"小体系内部"的散布。稿件 §4 的说法（`:546-547`）也承认这点：真正的结论是"占比随**排布**变、同一对分子两种几何就 97%/52%"，
   那是**变异性**结论，不是**量级**结论。

## 5. 结论：需要限定

**判定 = 需要限定**（不是"不成立"：两个数、符号、加性闭合、网格稳定性全部核过了，都能从工件重算；
也不是"支持"：口径被省掉了，而且省掉的口径正是本仓库代码自己设了闸门的那一条）。

限定后的措辞（可直接替换原句）：

> ωB97X-V/6-31G\*、网格 level 1、**未做 BSSE 校正**、单位 kcal/mol（`nlcsplit/logs/step_h.json`，甲烷行 `:93-99`、水行 `:52-58`）：
> VV10 项 **ΔE_NLC** 对**全量 ΔE_xc**（ΔE_xc = ΔE_xc^其余 + ΔE_NLC，分母含分子）之比 = **16%（水二聚体）～ 223%（甲烷二聚体）**，全表 7 个 S22 成员 + 苯二聚体第二构型。
> 223% 的含义必须连着说：分子分母同号（−0.517 / −0.232），没有取绝对值；超过 100% 是因为**其余那部分 XC 在这一行是排斥的（+0.285 kcal/mol）**，把分母抵到只剩 |ΔE_NLC| 的 45%。
> 这恰是本工具自己判定"分母抵消、不报占比、只报两个绝对项"的那一档（`nlcsplit/step_f_dispersion.py:130` 阈值 `|ΔE_NLC/ΔE_xc|>2.0`，全表唯一触发行）。
> **"不是小修正"要靠绝对量和正确的分母说**：甲烷二聚体的 VV10 单项 −0.517 kcal/mol（≈ −2.2 kJ/mol）**比整个算出来的结合能还大**
> （−0.66 kcal/mol 未校正；`evidence/l2cp/20260928T213839Z_centos-step_h_l2cp.out:16` 的 −0.466 kcal/mol 反泊松校正 ⇒ 110.9%），
> 而水二聚体那一行 VV10 只占结合能的 7.6%（CP 后 9.7%）——**同一套基准里，"能不能忽略"确实是逐体系的问题，不是逐体系类型的问题**。
> 不要把 16% 与"不是小修正"并列：16% 那一端是全表最像小修正的一行。

**三条必须避免的写法**（现稿/骨架稿已在犯）：
1. 说 "VV10 占 223%"（漏 "of ΔE_xc"，且分母含分子）——应写 "ΔE_NLC = 223% 的 ΔE_xc，因为余下 XC 为 +0.285 排斥"。
2. 把分子说成片段分解的 E_NL(A,B)——那是 `pint.becke` = −0.474，对应 **204%**，不是 223%。
3. 顺带引 `MAIN-skeleton.md:230` 的"100% vs 54%"——已被 level 1 的 97%/52% 取代（`paper/main.md:399`）。
