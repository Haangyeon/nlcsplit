## 二、**不许**写成这样（都是我这一轮差点写错、或查出来会写错的版本）

- ✗ "网格加密使苯二聚体(A) 的归属跨度翻倍。" —— 那是**未收敛残差的差**，不是物理效应。
- ✗ "八格的归属跨度都通过了网格收敛检验。" —— 五格有两个都够细的档；
  其余**三格**（苯-氨、苯-甲烷、苯二聚体(B)）最高两档含 level 0，表里明写 `NOT MEASURED`。
- ✗ "跨度对网格不敏感（全文）"。主判据（整条阶梯最坏相邻差）本轮仍是 **rc=3**，不是通过；
  rc=3 是诚实读数，**不许**为了让表变绿把 level 0 剔出阶梯——要说的话说在次级主张里，且次级主张不改退出码。
- ✗ 任何把 level 0/1/2 的跨度与**另一份 `partition.py` 哈希**的数并排的句子：
  合并前后同名档的含家族外跨度不同（水 level 1：0.0650 对 0.0433），跨哈希的"阶梯"量的是代码改动。
- ✗ **新查出的坑（两个口径，方向相反）**：正文 §3.4 与 §4.5 那句"从粗档往上走时跨度是**变窄**的"
  说的是**自建网格**那一列：level-0 的 `P_frz 跨度` 0.072 / 0.310
  （`evidence/centos/20260928T193520Z_centos-step_h_benz_l0.out`）对 Table 3 的 "span, own grids"
  0.032 / 0.219。本表量的是**同一公共网格上的归属跨度**，也就是 Table 3 的 "attribution only, one grid"
  那一列。两个量在 level-0→1 上方向不一致：公共网格上苯二聚体(A) 是 **0.0120 → 0.0274（变宽）**、
  苯二聚体(B) 是 0.2196 → 0.2196（不动），而自建网格 P_frz 是 0.072 → 0.032（变窄）。
  ⇒ 本表**不能**用来支撑或反驳"变窄"这个方向词；它只支撑"level 0 的跨度不可用"（两格外超门）。
  要保留方向词就得继续挂在自建网格那一列上，并写明它是自建网格口径。

## 三、引用时的三个口径纪律

- 档内自印跨度由全精度内部值算出，逐列重算会差**一个末位**（现规定容差 `MAX_ULP=1`）。
  本轮实测：52 组比对，最大偏差 1 个末位，0 组超容差。
  引正文就引**自印值**，引重算就注明重算；两者都指到同一个文件即可对质。
- 比值列自印与重算可以差在第二位小数（甲烷 level 2：档内印 2.56，表里重算 2.54）——
  那是"先舍入再相除"与"先相除再舍入"的差别，**不是** tie-out 失败；tie-out 只挂跨度列。
  预登记档位（≤2 / >10）离边界 0.46，本轮没有因它翻档。
- 点数一律是**分区后公共网格**口径（水 4 440 / 18 336 / 38 944；苯-水 11 528 / 47 920 / 101 400；
  苯二聚体(A) 18 448 / 77 072 / 163 488）。与"未分区 `gen_grid`"是两套数。
